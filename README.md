# กระปุก (แอปออมเงินออฟไลน์)

แอปตั้งเป้าหมายออมเงิน ฝาก/ถอนด้วยแผงตัวเลข ใส่รูปประจำเป้าหมาย ดูประวัติรวม
ธีมการ์ดโทนขาว น้ำเงิน ฟ้า พื้นหลังเรียบไม่มีเอฟเฟกต์เพื่อให้ลื่น มีปุ่มสลับภาษา ไทย/English ที่มุมขวาบน ใช้ฟอนต์ประจำเครื่อง
ใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต ข้อมูลเก็บในเครื่องเท่านั้น

## ไฟล์ในโฟลเดอร์

- `krapuk.html` ไฟล์เดียวรวมทุกอย่าง เปิดดูบนคอมหรือมือถือได้ทันที
- `www/` ซอร์สโค้ดแอป (index.html, style.css, app.js)
- `.github/workflows/build-apk.yml` ตัวสร้าง APK อัตโนมัติบน GitHub
- `build-standalone.py` สร้าง `krapuk.html` ใหม่หลังแก้โค้ดใน `www/`

## ได้ไฟล์ APK แบบง่ายที่สุด (ไม่ต้องลง Android Studio)

1. สมัคร GitHub (ฟรี) แล้วสร้าง repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github`)
3. เปิดแท็บ **Actions** รอ workflow **Build APK** รันเสร็จ (ราว 5-8 นาที)
   ถ้าไม่รันเอง ให้กด **Run workflow**
4. เปิดงานที่รันเสร็จ ดาวน์โหลด `krapuk-apk` ตรงหัวข้อ Artifacts แล้วแตกซิป จะได้ `app-debug.apk`
5. ส่งไฟล์เข้ามือถือ เปิดติดตั้ง (อาจต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

## สร้างเองในเครื่อง

ต้องมี Node.js 18+, JDK 17 และ Android SDK (หรือ Android Studio)

```
npm install
npx cap add android
npm run icons
npx cap sync android
cd android && ./gradlew assembleDebug
```

ไฟล์ที่ได้อยู่ที่ `android/app/build/outputs/apk/debug/app-debug.apk`

## หมายเหตุ

- APK เป็นแบบ debug ติดตั้งใช้เองได้เลย ถ้าจะขึ้น Play Store ต้องทำ release build และเซ็นกุญแจก่อน
- รูปประจำเป้าหมายเก็บแยกในเครื่อง ไม่รวมอยู่ในข้อมูลสำรอง (สำรองเฉพาะชื่อ ยอด และรายการ)
- ถอนการติดตั้งแอปแล้วข้อมูลจะหาย ควรกดสำรองข้อมูลไว้ก่อน
- เปลี่ยนไอคอนโดยแทนที่ `resources/icon.png` (1024x1024)
- รูปประจำเป้าหมายถูกย่อเหลือประมาณ 320 พิกเซลเพื่อประหยัดที่เก็บและโหลดเร็ว
